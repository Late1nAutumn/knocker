# Knocker 定时提醒

Windows 托盘常驻的定时提醒小工具。到点后播放指定音频，并在屏幕右下角弹出提醒窗口；确认后重新开始计时。

## 功能

- 按设定的提醒间隔计时，到点后：
  - 反复播放指定音频
  - 屏幕右下角弹出置顶窗口，显示本机当前时间和提示文字
- 弹窗操作：
  - **确认**：停止提醒，从此刻起重新按提醒间隔计时
  - **稍后提醒**：停止提醒，过“稍后提醒”设定的分钟数后再次提醒
- 在点击“确认”之前，计时始终暂停，不会累积多次提醒
- 可随时停止 / 开始计时（停止时会同时结束正在进行的提醒）
- 关闭或最小化主界面后缩到托盘，在后台运行
- 主界面和托盘悬停提示都能查看距下次提醒还有多久

## 运行环境

- Windows 7 及以上
- .NET Framework 4.x（Windows 10/11 自带，无需安装）

## 编译

双击 `build.bat`，会在同目录生成 `Knocker.exe`。编译前请先退出正在运行的 Knocker，否则 exe 被占用无法覆盖。

编译使用系统自带的 `csc.exe`（`%WINDIR%\Microsoft.NET\Framework64\v4.0.30319\`），不需要安装 Visual Studio 或 .NET SDK。

## 使用

1. 运行 `Knocker.exe`，程序启动后立即开始计时。
2. 在主界面设置：

   | 项目 | 说明 |
   |---|---|
   | 提醒间隔 | 两次提醒之间的分钟数（1–1440） |
   | 稍后提醒 | 点“稍后提醒”后再次提醒的分钟数（1–1440） |
   | 提醒音频 | 本地音频文件，支持 mp3 / wav / wma，可点“试听” |
   | 提示文字 | 弹窗中显示的文字，可多行 |

3. 状态栏右侧的 ▶ / ■ 按钮用于开始 / 停止计时。停止后再开始，会从头按提醒间隔计时。
4. 点“保存设置”。新的提醒间隔从下一次开始计时起生效；想立即生效，点“重新开始计时”。

### 托盘操作

- 鼠标悬停：查看剩余时间
- 双击：打开主界面
- 右键菜单：
  - 开始 / 停止
  - 重新开始计时（处于停止状态时也会恢复运行）
  - 打开主界面
  - 退出

## 自定义图标

图标来自程序目录下的 `icon.png`（附带一个模板，蓝底白铃铛，256×256）。用同名 PNG 覆盖即可替换，建议使用正方形、带透明背景的图片，尺寸不小于 256×256。

- 托盘、主界面图标：程序启动时读取 `icon.png`，替换后重启程序即可生效。
- exe 文件图标（资源管理器中显示）：编译时由 `build.bat` 自动把 `icon.png` 转成多尺寸 `icon.ico` 并嵌入 exe，替换后需重新运行 `build.bat`。
- 运行时找不到 `icon.png` 时，使用 exe 内嵌的图标。

## 配置文件

设置保存在 exe 同目录的 `knocker.ini`（UTF-8 编码），点击“保存设置”时生成。删除该文件即可恢复默认设置。

## 说明

- 同一时间只能运行一个实例。
- 不会开机自启动。如需自启，可把 `Knocker.exe` 的快捷方式放到 `shell:startup` 文件夹。
- 音频文件不存在或无法播放时，仍会弹出提醒窗口，只是没有声音。

## 文件

```
Knocker.cs    源码
build.bat     编译脚本
png2ico.ps1   PNG 转 ICO 脚本（由 build.bat 调用）
icon.png      图标模板，可替换
icon.ico      编译时生成
Knocker.exe   编译产物
knocker.ini   配置文件（运行后生成）
```
